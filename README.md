# Chocolate Sales Performance Analysis — SQL

End-to-end SQL analysis on chocolate sales dataset using MS SQL Server (SSMS).

## 🛠️ Tools Used
- SQL Server Management Studio (SSMS)
- T-SQL

## 🔍 Analysis Covered
- Data cleaning & null handling
- KPI metrics (total revenue, avg order value, top products)
- Country-wise sales contribution
- Monthly trend analysis
- Product performance ranking

## 🧠 SQL Concepts Used
CTEs | Window Functions | CASE WHEN | GROUP BY | Aggregations | Joins

## 📁 Files
| File | Description |
|------|-------------|
| `analysis.sql` | Complete SQL queries |
| `README.md` | Project documentation |

## 📌 Dataset
Chocolate sales dataset with salesperson, country, product, and monthly sales data.
